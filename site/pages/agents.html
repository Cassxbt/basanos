For agents

Check before you submit. Every time.

An agent that hunts bugs should not file a finding its own evidence cannot carry. Give it one tool, basanos_precheck, and it learns what proof is missing before a judge has to tell it.

git clone https://github.com/Cassxbt/basanos && cd basanos && npm ci claude mcp add basanos \ --env SERV_API_KEY=… --env DOLPHIN_API_KEY=… \ -- npx tsx src/mcp.ts
