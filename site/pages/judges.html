The rubric

Where to look, criterion by criterion.

Judged on creativity, user readiness and revenue potential. Each row points at something you can open or run, not a sentence to trust.

Creativity

A pre-submit gate for audit contests: the open model does the heavy reading, code owns the veto, SERV guards the hostile text and makes one bounded call. Backed not by accuracy claims but by bug/fix pairs: the verdict moves when the code moves.

Attack 04 above · bug/fix pairs on /proof · the Touchstone Pass

User readiness

Live on this site, an MCP tool a bug-hunting agent calls before it submits, a CLI with exit codes for CI, and an HTTP route. Every interface returns the same checksummed Assay Receipt. Demo scope: two closed contests, Karak in the browser and Kleidi through the API.
