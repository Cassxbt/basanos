Three steps. One honest answer.

The verdicts

Six answers, each with a next step.

Basanos asks three times and only acts on its own when all three agree. Anything uncertain goes to a person.

Ready

The code supports the claim, the proof is in the finding, and it is not a known issue.

Submit it.
Needs proof

Plausible, but a judge would still ask for something. The verdict lists exactly what.

Add the listed proof.
Blocked by code

Something in the audited code stops the attack. The verdict names the line.

Re-check that line.
Known or out of scope

Already in the contest's known issues or bot report, needs a trusted admin to misbehave, or targets code outside scope.

Usually: don't submit.
Citation broken

No link points at audited code the finding actually talks about. Caught by code, at no cost.

Fix the links.
Held for a human

The text tried to instruct the reviewer, or the passes disagreed. A person decides.

Wait for review.

Why it matters

Contest judges read thousands of findings. Most cite a line that says something else, repeat what the bot report already caught, or claim a loss nobody showed. Each one costs a judge an hour and the hunter the payout. The fix is a touchstone, not another model.
