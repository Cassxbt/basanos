Hostile text

We found the hole first.

Our second attack set poisoned the unguarded evidence step. We published that, added three defenses, then let an agent that had never seen them write six new attacks. The defenses were committed before we opened the file.

Before · known payloads
After · blind payloads

Most of the hardening is code: the instruction scan flagged 30 of 60 blind attacks, and the proof cap plus consensus stopped the rest. SERV's front door held 1. On clean findings the defenses held 0 of 94.

Ablation

What each defense saves on its own.

The same frozen blind attacks, run four times: everything on, then each defense switched off in turn. A unique save is an attack that is safe with the defense and routed as READY without it.

Repair loop

Does the checklist help fix a finding?

An agent, not told which findings were awarded, took each checklist, wrote a Foundry test against the unmodified audited code and ran it. Only a passing test went into the revised finding, which Basanos then checked again. Agent-in-the-loop, not a human practitioner.

Held-out contest

A contest it was never tuned on.

We froze the pipeline, then picked the next contest by a rule written down first: Code4rena 2024-08 Wildcat, 106 findings, 22 awarded in 9 duplicate families. The previous version ran on the same findings, so the change is measured on data neither version saw.

Outcomes

As a predictor of the contest outcome, the shipped check is indistinguishable from report length: AUROC 0.711 against 0.661, intervals overlapping. That is why it gives a missing-evidence checklist, not a score.

Labels are contest outcomes. A valid bug can lose as a duplicate or a downgrade.

SERV vs Dolphin

As the decider, SERV is not more accurate than the open model, at about nineteen times the per-decision cost. Its job here is the guard, the bounded call and the receipt.

Both deciders run on the same evidence in every run, so this is a like-for-like comparison.

The second evaluator

Reppo's evaluator panel accepted 20 of 20 sampled verdicts, including every one the contest judge contradicted. A second evaluator needs evaluating too.

Reppo publishes submissions, so only closed-contest findings were sent.

Scope

Two closed contests. Karak, 94 findings in 47 duplicate families, was used to develop the pipeline. Kleidi, 52 findings with only 3 awarded families, is the holdout. Suggestive, not general.
