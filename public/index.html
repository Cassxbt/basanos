Rub the finding against the code before you submit it.

Paste an audit-contest finding. Basanos checks every code link against the audited commit, has an open model read the entire in-scope source, and asks SERV for one bounded verdict with the exact proof a judge would still need.

About $0.001 per check. Findings are sent to Dolphin and SERV for this check and are not stored here.

No streak yet.

Assayers rubbed gold on a black stone and read the streak it left. Basanos does the same with a finding: the colour of the streak is the verdict, and underneath is everything that would make it stronger.

How it decides

01 · code

Citations against the audited commit

Every GitHub link is resolved at the commit it names and compared with the audited code. Fabricated lines, missing files and out-of-scope files stop here, with no model call.

02 · Dolphin

An open model reads everything

DeepSeek-V4.1-Flash on Dolphin reads the full in-scope source (about 43k tokens) plus the contest's known issues, and records what the code actually shows. About $0.0005.

03 · SERV

One bounded verdict, guarded

SERV Reasoning makes a single decision from the evidence record, with Prompt Guard screening the untrusted finding text. Code still owns the veto: SERV cannot promote a claim the source read did not support.

What we measured

94 Karak findings that were submitted as High or Medium, scored against what the contest judge decided, in two full runs. Read the plan and every number in the repository; the plan was committed before any run.
